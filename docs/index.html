ReFold

Training-Free Reversible Inter-Turn Context Folding for Long-Horizon Agents

Repeated output becomes a stub and finished steps fold into one-line notes. No extra model calls, no training, and anything removed can be restored.

Demo

Method

The agent's history is never edited. Before every model call, ReFold renders a shorter prompt from it, with no extra model call and nothing lost for good.

How each part works, with examples from a real run
Deduplicate

Repeated output becomes a stub

When a file range, a search result or a command output repeats one that an earlier turn still shows, the later copy becomes a stub that points to that turn. For a long span the stub keeps the top-level class and function signatures, so the agent can still find its way around.

Fold

Finished turns fold into a one-line note

Every reply starts with two short lines: PROGRESS says what the turn does, STALE names earlier turns whose output the agent will not read again. They come with the normal reply, so there is no extra model call.

𝐚t=PROGRESSt⊕⟨STALEt⟩⊕𝐚˜t\mat{a}_t = \sc{PROGRESS}_t \oplus \langle\sc{STALE}_t\rangle \oplus \tilde{\mat{a}}_t St=St−1∪(STALEt∩{t−k,…,t−1})\class{c-fold}{S}_t = \class{c-fold}{S}_{t-1} \cup (\sc{STALE}_t \cap \{t{-}k, \dots, t{-}1\})

StS_t starts empty and only takes turns from the last kk. Behind the boundary, a turn in it leaves the prompt, reply and output together; adjacent folded turns share one note.

Chunked rendering

The cached prefix changes once every 𝒌\boldsymbol{k} turns

Both operators act only behind a boundary btb_t that moves every k=3k = 3 turns; later turns are sent as received. Between two moves the prompt only grows at its end, so the server keeps reusing its cache.

bt=max⁡(0,k⌊t−kk⌋)\class{c-chunk}{b}_t = \max\!\left(0,\,k\!\left\lfloor\frac{t-k}{k}\right\rfloor\right)
Restore

Anything removed can come back

Every stub and note names the turns it replaces. restore <step> is answered from the history: the original reply, command and output are appended at the end of the prompt, nothing runs again, and the cached prefix stays as it is.

Code

ReFold is a plugin for mini-swe-agent: a rendering hook before every model call and a few lines of prompt. The agent's tools and loop stay the same. The code and the scripts behind every table and figure are on GitHub.

YupengSu/ReFold
The prompt lines ReFold adds
Replaces the first item of the response format
Begin every response with these two lines, then your reasoning and your bash tool call:
  PROGRESS: <one short line on what THIS step does>
  STALE: <step numbers whose output you will not read again, or `-` if none>
Each earlier tool output is labeled `[step N]`.
…
Only the last 3 steps before this one can still be named; older numbers are ignored, so saving up a big cleanup for later is wasted.
Appended to the system prompt
Context management: to save tokens, the harness omits parts of earlier tool outputs that already appear elsewhere and folds steps you have marked STALE. Every omission is marked by a `[context-manager]` note, which is NOT a shell error: it says what was omitted and where the same content still is. The bash command `restore <step>` shows a step's output again exactly as first shown, without running anything; re-running the original command shows its current state instead. …

From Appendix C.2 of the paper, for k=3k = 3. Every tool output is also prefixed with its step number, and a reply without the two lines gets a reminder.
